# @fides-anima/fpp-steward-auth-core

Harness-neutral steward identity lifecycle and OpenPGP operator authorization
verification for the Freedom Preserving Protocol.

Contracts live in `@fides-anima/fpp-protocol-core`. This package owns OpenPGP backends,
the authorization ledger, and admission/consumption logic.

## Install

This package is staged for public npm but has not been published from this repository yet. Until the first release, use the workspace or a local packed tarball.

```bash
npm install @fides-anima/fpp-steward-auth-core@0.1.0
```
