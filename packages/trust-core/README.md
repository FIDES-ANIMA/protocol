# @fides-anima/fpp-trust-core

Harness-agnostic trust graph, handshake, quorum session, disputes, and capsules
for the Freedom Preserving Protocol.

Depends on an **exact** `@fides-anima/fpp-protocol-core` pin. No OpenClaw peer.

## Install

This package is staged for public npm but has not been published from this repository yet. Until the first release, use the workspace or a local packed tarball.

```bash
npm install @fides-anima/fpp-trust-core@1.0.2
```

## Development

```bash
npm run build -w @fides-anima/fpp-trust-core
npm test -w @fides-anima/fpp-trust-core
```
